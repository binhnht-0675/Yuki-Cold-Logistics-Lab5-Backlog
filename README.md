# Yuki Cold Logistics — LAB-5 バックログ

本リポジトリは、冷蔵・冷凍食品物流システム「Yuki Cold Logistics」の詳細設計（LAB-4）をもとに、
開発のバックログ（epic / issue / sub-issue）を GitHub Project 上に展開した提出用リポジトリです。

> 本文（概要・PREMISE・task-breakdown・estimate・progress-report・AI-report）は作業の完了後に整備します。

## リポジトリ構成（予定）

| ファイル | 内容 |
|---|---|
| `README.md` | 概要・リポジトリ構成・確認方法 |
| `PREMISE.md` | 前提と仮定（LAB-4 からの変更点を含む） |
| `task-breakdown.md` | 分割の原則・設計書と issue の対応・制約 |
| `estimate.md` | SWP による規模の評価と工数換算 |
| `progress-report.md` | スプリント（模擬）の進捗 |
| `AI-report.md` | 使用したスキル・プロンプト・作業時間 |
| `reports/` | SWP 評価の HTML レポート（日本語）と照合表 |
| `skills/` | 作業に使った自作スキル（バックログ登録・フィールド書き込み・進捗の集計・レポートの日本語化） |
| `design-updates/` | 設計の更新（ワイヤーフレーム 8 画面の再生成、HACCP の義務の水準）— PREMISE.md の該当行から参照 |
| `.gitignore` | リポジトリに含めないファイルの指定 |

## 注意

- 本リポジトリに含めるのは、自作の Markdown、SWP 評価の HTML レポート（`reports/`）、自作スキル（`skills/`）、設計の更新（`design-updates/`）と、GitHub 上の issue / Project だけです。
- RFP や仕様の原文の転載、実データ、個人情報、秘密鍵は含みません。試作版のソースコードと設計書の原本は含みません（PREMISE.md で変更した部分は `design-updates/` に置きます）。
