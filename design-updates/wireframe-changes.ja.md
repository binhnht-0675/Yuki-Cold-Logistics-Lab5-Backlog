# ワイヤーフレームの再生成（8 画面）

LAB-4（詳細設計、2026-10-12 提出）に対する講師講評（2026-10-19）の指摘に基づき、次の 8 画面のワイヤーフレームを最新の画面仕様から作り直した。画面仕様（本文）を正とする。PREMISE の P-S21 に対応する。

## 1. 講評の要旨と対応

| 講評の要旨 | 対応 |
|---|---|
| 処理不可のダイアログに、画面仕様では出さない内部の規則コードが描かれている | 8 画面とも内部の規則名・応答コードを外した（共通仕様 CS-07 7.4。業務ルール番号 BR- / FR- / NFR- だけは仕様どおり出す） |
| 古いボタン名・必須の印の誤り | ボタン名は試作版の画面の文言（実装済みの画面）または画面仕様（設計の画面）と一字ずつ合わせ、必須・任意の印を画面仕様 4.1 の Required と合わせた。4.1 が 4.2・6 章と食い違う 4 項目（SCR-02 A-5、SCR-17 C-6・C-7、SCR-20 D-2）は PREMISE の「後」の Required で描いた（§5） |
| POD の写真・位置情報が、仕様では任意なのに必須として描かれている | SCR-17 の配達不可の写真・位置情報を「任意」にした |
| 温度アラートで期限超過の行が下に並んでいる（並び順が逆） | SCR-23 を確認の期限が早い順（期限超過が先頭）にした。SCR-05・SCR-25 の並び順も画面仕様に合わせた |
| 画面仕様の項目と画像の注釈を照らし合わせる | 8 画面とも、画像のピンを画面仕様 4.1 の項目 ID にし、照合を自動化した（§3） |

照合は、画面仕様 4.1 の表とワイヤーフレームの DOM（ピンの ID・印・注釈の表）を突き合わせる自動のテストで行った。結果は、4.1 の項目 ID・Required の印・注釈の表の照合で 0 件の不一致（文言・並び順・ダイアログの内容は人が確認）。この照合は項目の種別・ボタンや見出しの文言・並び順・ダイアログの文は見ないため、それらは試作版の画面の日本語の文言と画面仕様に照らして人が確かめた。

4.1 の Required が 4.2・6 章と食い違う 4 項目（上の表の「PREMISE の「後」で照合した項目」）は、例外として一覧に明記し（画面・項目 ID・PREMISE の行・直した Required）、その Required と照合した。例外の項目は、条件付きの印（破線の札）と、PREMISE の行番号を付けた破線の枠が図にあることも確かめる。画面仕様 4.1 を直したら、例外の行を外す（4.1 と例外の「前」の値が食い違うと警告が出る）。

同じ照合を残り 27 画面にも広げ、画面仕様が変わるたびに走らせる作業を sub-issue にした（PREMISE P-S21）。
