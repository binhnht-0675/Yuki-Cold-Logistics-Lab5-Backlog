SCR-12引当結果

配送計画者（ROLE-004）が受注の一覧から受注を開き、「引当を実行」でロットを引き当て、引き当てたロットと除外したロット（除外の規則と比べた値）を確かめる画面。納品期限ルールが未設定の契約の受注は業務確認待ちになり、営業・契約管理（SALES_CONTRACT）が理由をつけて承認するまで引当しない。
LAB-4（詳細設計、2026-10-12 提出）に対する講師講評（2026-10-19）の指摘に基づき、画面仕様 SCR12_ALLOCATION_RESULT_SPEC.md（version 0.4.1）の 4.1・4.2・5・6 章から作り直した。画面仕様（本文）を正とする。表示している値は仮の例。

4遮断される分岐（処理不可）

画面仕様 5 章 エラー制御・5.2。「処理不可」ダイアログ（共通仕様 CS-07 7.4）で出す: タイトル「処理不可」、理由 1 文、比較した値、次の対応、ボタン「閉じて続ける」だけ。この画面の却下は業務ルール番号ではないため「ルールコード」の行は出ない。409 のときは最新の状態を読み直してから出す。

#遮断される状況理由（1 文）比較した値次の対応
1検証済以外の受注に引当（同時の 2 要求の後発も）検証済みの受注だけ引当できます。ほかの操作で状態が変わった可能性があります現在の状態画面を最新の状態に更新しました。受注の状態を確認してください
2業務確認待ちでない受注を承認この受注は業務確認待ちではありません—画面を最新の状態に更新しました。受注の状態を確認してください
3起票者本人が承認（画面では無効化済み）自分が登録した受注は承認できません（自己承認の禁止）。別の営業・契約管理の担当者が承認してください—登録した人とは別の、営業・契約管理の担当者に承認を依頼してください
4出発後・取消済みの受注を取消この状態の受注は取り消せません現在の状態受注の状態を確認してください。出発後の受注は取り消せません
5検証済以外に欠品出荷を確定欠品出荷を確定できるのは検証済みの受注だけです現在の状態受注の状態を確認してください
6引当が 0 のまま欠品出荷を確定 / すでに満量欠品出荷を確定できるのは、一部だけ引き当てた受注だけです / 受注数量すべてを引き当て済みのため、欠品出荷の確定は不要です数量 / 引当済みの数量引当の数量を確認してください
7一部引当のあとに未承認の業務確認の対象が出た受注に欠品出荷を確定承認されていない業務確認の対象があるため、欠品出荷は確定できません保留の理由再引当を実行すると業務確認待ちになります
8受注が存在しない / 読めない受注が見つかりません—（なし。画面の「← 引当結果の一覧へ戻る」は使える）
9ロールが違う（API を直接呼んだとき）引当は配送計画者だけが行えます / 受注の操作（登録・取消・欠品出荷の確定）は配送計画者だけが行えます / 業務確認の承認は営業・契約管理だけが行えます / 引当結果を見られるのは配送計画者・営業・契約管理だけです—（なし）
理由の欠落・長すぎ（入力の誤り）はダイアログ / パネルの欄の直下に出し、「処理不可」にはしない。除外されたロット（業務ルール）は却下ではなく、主画面 B の「除外されたロット」の表で示す。
