SCR-02入庫検査

到着済みの入荷予定の明細を選び、仕入先ロット・数量・日付・実測温度・梱包状態・証拠写真（米・牛はトレースの項目も）を記録して「検品を確定」する。期限種別はマスターから読むだけ。LAB-4（詳細設計、2026-10-12 提出）に対する講師講評（2026-10-19）の指摘に基づき、画面仕様 SCR02_RECEIVING_INSPECTION_SPEC.md（version 0.4.1）の 4.1・4.2・5・6 章から作り直した。画面仕様（本文）を正とする。表示している値は仮の例。

2注釈（画面仕様 4.1 の項目）

1 行 = 4.1 の 1 項目。項目名・種別・Required は 4.1 のとおり（A-5 の Required だけは PREMISE P-S25 で直した値）。最後の行は本番版で足す部分（PREMISE）。

ID項目名（4.1 の Item Name）種別Required画面での表し方・補足
A-1仕入先ロットText box必須空で始まる（事前通知の値は入れない）。200 文字以内（見えない文字を除いて整えた後の値で数える）。事前通知と違うとトレース不一致として自動で隔離（大文字小文字は区別しない）。
A-2受入数量Text box必須0〜999999999.999、小数 3 桁まで。0 でも可（全数却下・全数保留）。
A-3却下数量Text box任意空 = 0。0 より大きいと理由（A-5）が必須。
A-4保留数量Text box任意空 = 0。0 より大きいと保留分のロットを別に作り、常に隔離する。
A-5理由Text box条件付き必須Required は PREMISE P-S25 の「後」（4.1 では「必須」）。200 文字以内の自由入力（コード表なし）。却下・保留の数量が 0 より大きいときだけ必須 — 欄の下のヒント「却下・保留の数量があるときは必須です」。
A-6製造日日付入力（4 値外）必須送る値は YYYY-MM-DD、画面の表示は YYYY/MM/DD（PREMISE P-S04・P-S26）。
A-7期限日日付入力（4 値外）必須製造日より前は不可（「期限日が製造日より前になっています」）。期限の種別は入力させない（A-8）。送る値は YYYY-MM-DD、画面の表示は YYYY/MM/DD（PREMISE P-S26）。
A-8期限種別（マスター・変更不可）Label-賞味期限 / 消費期限を SKU マスターから表示するだけ。
A-9実測温度（°C）Text box必須小数 1 桁まで、−60.0〜+60.0（丸めない）。ヒント「小数 1 桁まで（例: 4.0、-18.0）」。温度帯の方針の外 → ロットを自動で隔離 + 逸脱ケース（境界は適合）。
A-10梱包状態Text box必須200 文字以内の自由入力。
A-11証拠写真ファイル選択（4 値外）必須1〜10 枚。「ファイルを選択」→ 縮小して送信 → ファイル名の行（× で外す）。送信中はボタンが「アップロード中…」で、「検品を確定」も押せない。
A-12ラベルの期限種別がマスターと異なるチェックボックス（4 値外）任意保存しない。チェックして確定すると止めて例外イベントを 1 件記録し、処理不可ダイアログを出す（1 章の最後の図）。
A-13取引 ID / 取引先 / 産地（**米レーンのみ**）Text box必須米のレーンだけ。3 つとも必須（欠けると「米の取引 ID・取引先・産地をすべて入力してください」）。欄の下に「事前通知: …」。
A-14牛の個体識別番号（10 桁）（**牛レーンのみ**）Text box必須牛のレーンだけ。数字 10 桁（全角数字は半角に直して受ける）。欄の下に「事前通知: …」。
A-15（非表示）送信キー非表示（4 値外）必須画面には出ない。画面が自動で作り、同じ内容の再送では同じキー、内容を直したら新しいキーにする（二重のロット作成を防ぐ）。
B-1明細の行Button-SKU・品名・事前通知の数量・入荷行の状態（入荷行がなければ「未確定」）。選択中は太枠。押すと入荷行を開く（なければ作る）。
B-2検品を確定Button-送信中は「確認中…」で押せない。写真のアップロード中も押せない。
B-3再試行（入荷行を開く）Button-入荷行を開けなかったとき、その明細の右欄に理由 1 文 +「再試行」。DB に届かないときは「システムを再起動しています…」の表示の再試行。
B-4再試行（一覧の読み込み）Button-予定の一覧の読み込みで DB に届かないときの「再試行」。
P-S01測定時刻（本番版で追加）時刻入力必須（PREMISE P-S01: 測定時刻を逸脱ケースの記録に必ず渡す）実測温度を測った時刻（JST）。温度逸脱で自動で作る逸脱ケースに、到着時刻ではなくこの時刻を記録する。ゾーンと記録者（検品の操作者）は画面の入力ではなく、確定の処理が渡す。
P-S12仕入先ロットのスキャン（本番版で追加）スキャン入力の切り替え-仕入先ロット（A-1）をバーコードスキャナでも入れられるようにする。手入力も残す。部品の形は棚入れ（SCR-05）のスキャン入力に合わせる想定（仮の図）。
P-S03「必須」の共通表示（本番版で追加）表示-この図の「必須」の黒いラベルが P-S03 で足す表示。試作版の画面には必須の印がない。
P-S04日付の表記（本番版で統一）表示の決まり-画面に出す日付は YYYY/MM/DD（製造日・期限日の欄、事前通知の日付）。
P-S25理由の「必須」の印（条件付き）表示の決まり（本番版で変更）-PREMISE P-S25。却下・保留のどちらかが 0 を超えたときだけ A-5 に「必須」の印を出す。
