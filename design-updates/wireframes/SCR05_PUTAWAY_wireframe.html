SCR-05棚入れ

センター作業者が、検品の済んだロットをスキャンし、提案されたロケーション（最大 3 件）から「この位置に置く」を押すか、ロケーションをスキャンして棚入れを確定する。画面名は PREMISE P-S05 により「棚入れ」（試作版の表記は Put-away）。LAB-4（詳細設計、2026-10-12 提出）に対する講師講評（2026-10-19）の指摘に基づき、画面仕様 SCR05_PUTAWAY_SPEC.md（version 0.4.1）の 4.1・4.2・5・6 章から作り直した。画面仕様（本文）を正とする。表示している値は仮の例。

2注釈（画面仕様 4.1 の項目）

1 行 = 4.1 の 1 項目。項目名・種別・Required は 4.1 のとおり。最後の行は本番版で変える部分（PREMISE）。

ID項目名（4.1 の Item Name）種別Required画面での表し方・補足
A-1ロットをスキャンText box必須最初の操作。コードの中身はロット ID（UUID の形。全角・大文字・前後の空白は整えて受ける）。形が違えば API を呼ばず、入力欄の下にブロック「ロットのコードではありません。…」。
A-2ロケーションをスキャンText box必須ロットを選んだ後に同じ入力欄がこの名前に替わる。ロケーションコード（例 C-01-01）、64 文字以内。
A-3スキャンモードButton-入力欄の名前の右のトグル。表示は「スキャンモード: オン」/「スキャンモード: オフ」（既定はオン）。オンの間だけ入力欄へ自動でフォーカスする（手入力中・ダイアログ表示中は奪わない）。
A-4棚入れ待ちのロット（選択リスト）選択リスト（4 値外 — ロットごとのボタンの一覧）任意ロット未選択のときだけ出る。SKU・ロット ID の先頭 8 文字・場所・状態。押すとスキャンしたのと同じ。上限 100 件に達すると「すべては表示していません（表示できる件数の上限に達しました）」。
A-5この位置に置くButton-提案 1 行に 1 つ（高さ 48px）。そのロケーションコードで棚入れを確定する（スキャンと同じ）。送信中は押せない。
A-6ロットを選び直す / 次のロットをスキャンButton-ロットの選択を外して最初の状態へ戻す。「ロットを選び直す」は棚入れの送信中は押せない。「次のロットをスキャン」は完了の後に出る。
A-7送信Button-入力欄の横（Enter と同じ）。空のとき・確認中は押せない。確認中の表示は「確認中…」。
A-8再試行Button-棚入れ待ちの一覧・提案の読み込みで DB に届かないとき。同じ読み込みをもう一度行う。
A-9閉じて続けるButton-処理不可ダイアログの唯一のボタン（右上の × はない）。閉じるとスキャン欄へフォーカスが戻る。
B-1ロット IDLabel-選んだロットの ID（UUID の形）。完了の表示にも「ロット ID：…」を出す。
B-2状態バッジLabel-利用可能 / 隔離 / 保留 / 解除 / 廃棄。
B-3数量Label-ロットの手持ち数量（在庫移動の合計）。
B-4現在のロケーションLabel-「現在 IN-01」の形。
B-5提案されたロケーションLabel-提案の見出し。0 件のときは「置けるロケーションがありません」。並びは空き容量の多い順（上限なしは先頭）→ ロケーションコード（PREMISE P-A03 の仮定どおり変えない）。
B-6提案のロケーションコードLabel-提案 1 行に 1 つ。隔離・保留のロットには隔離用ロケーション（C-Q-01 など）だけを提案する。
B-7温度帯チップLabel-常温 15〜25 °C / 冷蔵 0〜5 °C / 冷凍 −18 °C 以下。
B-8空き容量Label-「空き 160 / 200」の形。容量の上限がない位置は「空き 上限なし」。
B-9スキャン結果（一致 / ブロック）Label-一致 = 棚入れの完了「{元} → {先} に棚入れしました（数量 …）」+「ロット ID：…」（保管位置からは「移動しました」）。ブロック = 入力欄の下に理由 1 文（ロットのコードでない・権限なし・DB に届かない・想定外）。業務の却下はブロックではなく処理不可ダイアログ。
P-S05画面名「棚入れ」（本番版で変更）表示-見出し・メニュー・パンくずの「Put-away」を「棚入れ」に統一する。入庫検査（SCR-02）の結果通知のリンクも「棚入れ へ」になる。
P-S04日付の表記（本番版で統一）表示の決まり-この画面に日付の欄はない。出すときは YYYY/MM/DD。

3状態バリエーション

4処理不可・エラー（画面仕様 5 章のエラー制御・5.2）

棚入れの確定が業務の規則で止まると処理不可ダイアログ（タイトル「処理不可」・理由 1 文・比較した値・次の対応「提案されたロケーションから選ぶか、スキャンし直してください」・ボタン「閉じて続ける」）。内部のコードは出さず、「ルールコード」の行もない。提案の読み込みで起きる #10・#11 はダイアログではなく提案の場所に 1 文。

#止まる状況理由文比較した値
1ロケーションコードが存在しないそのコードのロケーションはありません（なし）
2入荷口・出荷口を指定保管用ではないロケーション（入荷口・出荷口）には置けませんロケーションの種別 ほか
3温度帯違いロットの温度帯と、ロケーションの温度帯が一致しませんロットの温度帯 / ロケーションの温度帯
4ロケーションが閉鎖中このロケーションは閉鎖中ですロケーションの状態
5隔離・保留のロットを通常のロケーションへ隔離・保留中のロットは隔離用ロケーションにしか置けませんロットの状態 / 隔離用ロケーション
6通常のロットを隔離用ロケーションへ通常のロットは隔離用ロケーションに置けません同上
7今と同じロケーションすでにそのロケーションにありますロケーション
8容量超過ロケーションの空き容量が、ロットの数量より少ないため置けません数量 / 空き容量
9提案の 3 件にない（有効でも不可）提案されたロケーションの中にありません。提案外のロケーションへの棚入れは本プロトタイプの範囲外の機能です（同上の比較値）
10ロットが見つからないロットが見つかりません（なし）
11ロットが廃棄済み、または手持ち 0このロットは移動できません（廃棄済み、または在庫がありません）現在の状態 / 数量
12ロットの一部がまだ出荷口にあるこのロットの一部が出荷口にあるため、棚入れできません。出荷口の荷を積込または棚へ戻してから、もう一度お試しください出荷口の数量 / 車上の数量

権限なし・DB に届かない・想定外の失敗はダイアログではなく、入力欄の下のブロック（B-9）に 1 文で出す。
